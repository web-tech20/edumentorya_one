Démontrer que toute matrice symétrique réelle vérifiant A³ = A est diagonalisable dans une base orthonormée et déterminer précisément son spectre Sp(A).

Note de Démonstration Académique

Réf. SPECTRE-SYM-03 • Algèbre Matricielle

Théorème & Corollaires

Soit A ∈ ℳₙ(ℝ) une matrice vérifiant l'hypothèse de symétrie réelle (Aᵀ = A) et la relation algébrique A³ - A = 0. La résolution rigoureuse s'articule en trois étapes canoniques :

1. Polynôme annulateur et scindabilité

Considérons le polynôme P(X) = X³ - X = X(X - 1)(X + 1). Par hypothèse, P(A) = 0, donc P est un polynôme annulateur non nul de A.

Le polynôme P est scindé sur ℝ à racines simples dans { -1, 0, 1 }. D'après le critère fondamental de réduction, A est diagonalisable sur ℝ.

2. Analyse spectrale et valeurs propres possibles Sp(A) ⊆ {-1, 0, 1}

Toute valeur propre λ ∈ Sp(A) est obligatoirement racine de tout polynôme annulateur. Dès lors :

P(λ) = 0 ⟹ λ(λ - 1)(λ + 1) = 0 ⟹ Sp(A) ⊆ {-1, 0, 1}

Le spectre réel est ainsi un sous-ensemble non vide de ces trois valeurs discrètes.

3. Application du Théorème Spectral pour matrices symétriques réelles

Puisque A ∈ 𝒮ₙ(ℝ) (symétrique réelle), le Théorème Spectral garantit l'existence d'une matrice orthogonale P ∈ 𝒪ₙ(ℝ) et d'une matrice diagonale D telles que :

A = P D Pᵀ \quad \text{avec} \quad Pᵀ P = Iₙ

Les sous-espaces propres associés E_{-1}(A), E₀(A), E₁(A) sont deux à deux orthogonaux, formant une décomposition orthogonale directe de ℝⁿ.

Remarque méthodologique Concours EPAC / Agrégation

Ne confondez pas A³ = A avec un projecteur (P² = P). Ici A² est un projecteur orthogonal ((A²)² = A⁴ = A² et (A²)ᵀ = A²), tandis que A est une symétrie orthogonale sur son image Im(A²).
